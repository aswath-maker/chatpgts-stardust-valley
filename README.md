# ChatGPT's Stardust Valley

A fresh, standalone Three.js + Vite prototype based on the supplied design document. This repository is intentionally separate from the pre-existing Stardew Valley repository.

## Milestone 0.1: Walk the town
- Third-person movement and mouse orbit camera
- High-poly anime-inspired protagonist and environment
- Meridian town, Town Hall, roads, river and bridge
- Forest edge with procedural trees and fireflies
- Day/night lighting and clock
- Start screen with protagonist name
- Basic save/interact hooks
- High-poly geometry, improved lighting, tone mapping, and 2x pixel-ratio cap

## Run
```bash
npm install
npm run dev
```
Then open the Vite URL shown in the terminal.

## Controls
W moves forward relative to the camera, S moves backward, A/D strafe, arrows move similarly, mouse orbits, Shift sprint, Space jump, E interact, T save, F whistle for Sora, Esc settings placeholder.
